Takes the OVA from XDR/Workflows and allows registration of a remote server to your account via a python script.

Official repo for this script will be updated at https://github.com/sholl-cisco/xdr-remote-register which also includes OVA instructions if not using dCloud.

There are planned changes to the remote server packaging for Workflows and Cisco XDR that will at some point resolve the need for this script to deploy a remote server on non-VMWare virtualization.
