# LTRAI-1647: Agentic Ops with Cisco Workflows

## Purpose
This purpose of this lab guide is to walk through how to setup ambient/agentic operational response with Cisco Workflows.

## Introduction

We will be using a virtual network topology in Cisco dCloud that generates events through splunk to Csico Workflows.

Components you will encounter in this lab:

* Cisco Workflows (in Meraki Dashboard)
* Splunk
* ThousandEyes
* Cisco CSR100v virtual routers 
* LLM integration (Claude Opus 4.5)
